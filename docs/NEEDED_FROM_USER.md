# Needed From User

현재 포트폴리오의 기본 정보와 프로젝트별 네 사례는 작성됐다. 아래는 사실을 더 강하게 증명하거나 이력서와 표기를 통일할 때 필요한 자료다. 자료가 없어도 확인되지 않은 수치나 장애 증상을 만들어 채우지 않는다.

## 다:서

- [ ] Google OAuth 장애에서 본인의 독립 수정안, pair work 또는 최종 반영 경위를 보여주는 기록이 있으면 공동 기여 범위를 보강한다. 현재 최종 callback commit은 팀원 명의로 확인된다.
- [ ] refresh cookie와 자동 재발급의 브라우저 E2E 증거가 있으면 검증 범위를 갱신한다.
- [ ] 강원SW 페스티벌 출품과 졸업작품 장려상의 날짜·상장·행사 자료를 확인한다.
- [ ] router 분리 전후 파일 대응표가 있으면 구조 개선의 변경 범위를 구체화한다.

My Page API 정리와 router 분리는 장애 대응이 아닌 후속 구조 개선으로 확정했다. My Page의 장애 증상을 새로 요청하거나 만들어내지 않는다.

## AI Mental Care

- [ ] 추가 질문의 적절성과 후속 입력을 반영한 추천 관련성을 검증할 사례나 평가셋이 있으면 기록한다. 현재 별도 키워드 감지 규칙이나 품질 개선율은 확인되지 않는다.
- [ ] Cloud 배포 로그, 재현 가능한 수동 검증 기록이나 공개 가능한 발표 자료가 있으면 검증 범위를 보강한다.
- [ ] 루틴 310건의 검수 기준과 적절·부적절 검색 사례가 있으면 정리한다.

## 문서 간 표기

- [ ] 이력서의 프로젝트명 `다서`와 포트폴리오의 `다:서`를 공식 표기로 통일한다.
- [ ] 이력서 Google Doc을 공개 포트폴리오에 연결할지, 연결한다면 보기 권한을 어떻게 설정할지 결정한다.
- [ ] 자격 3개의 취득일을 공개하려면 증빙을 확인한다. 현재 포트폴리오와 이력서에는 자격 이름만 적었다.
