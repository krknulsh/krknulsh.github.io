## Priority C — 콘텐츠 품질 향상용

각 프로젝트에 대해 아래 질문에 답하면
README 및 면접 대비 내용의 질이 크게 올라간다.

### Project Question Template

1. 이 프로젝트를 왜 만들었는가?
2. 사용자가 겪는 문제는 무엇이었는가?
3. 팀에서 정확히 무엇을 담당했는가?
4. 본인이 직접 작성한 핵심 기능 3개는?
5. 가장 어려웠던 기술 문제는?
6. 문제의 원인은 무엇이었는가?
7. 어떤 대안을 검토했는가?
8. 왜 최종 방식을 선택했는가?
9. 결과적으로 무엇이 개선되었는가?
10. 다시 만든다면 무엇을 바꾸겠는가?

AI Mental Care에 대해서는 상당수 정보가 이미 정리되어 있으므로
추가 답변 없이도 1차 작성 가능하다.

Multi-LLM 프로젝트는 위 질문 중
3~9번에 대한 추가 정보가 있으면 좋다.
